# Инструмент визуализации графа зависимостей

Учебная практическая работа №2 по дисциплине «Конфигурационное управление».
**Вариант №16.**

## 1. Общее описание
CLI-приложение на Python для визуализации графа зависимостей пакетов.
На текущем этапе (Этап 1) реализован минимальный прототип, который считывает настройки из TOML-файла, проверяет их и выводит на экран.

## 2. Функции и настройки
Приложение принимает один параметр командной строки:
*   `--config <path>` — путь к файлу конфигурации в формате TOML.

**Параметры в TOML:**
*   `package_name` — имя анализируемого пакета.
*   `repo_url` — URL репозитория или путь к тестовому файлу.
*   `work_mode` — режим работы (например, real или test).
*   `package_version` — версия пакета.
*   `image_filename` — имя файла для сохранения графа.
*   `ascii_tree` — режим вывода в виде ASCII-дерева (true/false).
*   `max_depth` — максимальная глубина анализа.
